# ПАЦИЕНТ НОЛЬ — контекст проекта

## Что это за игра

Топ-даун изометрическая симуляция заражения. Игрок — нулевой пациент в толпе
из 500 человек. Эвакуация полностью удалена из игрового процесса.
Текущая победа: охват 100% (заражённые, включая LATENT, плюс погибшие).
Поражение: смерть игрока от огня полиции. Ареста и лимита времени нет.
Роль убийств в победе ещё подлежит отдельной игровой приёмке.

Ядро фана: **каскад из одной точки** плюс **постоянный выбор жертвы**.
Игра про то, кого схватить, когда уйти и куда направить орду.

## Управление

- **WASD** — движение, мышь задаёт направление взгляда
- **Shift** — спринт
- **ЛКМ (удерживать)** — захват; **Space** останавливает шкалу (вырвался / заразился / убит)
- **ПКМ** — движение / атака орды; **F** — следовать; **H** — удерживать
- **Alt + Sprint** — бросок-лунж к ближайшей цели
- **Esc** — пауза / меню
- **R** — рестарт

## Главные механики

1. **Шкала захвата.** Удерживать ЛКМ рядом с жертвой, нажать Space в нужной зоне.
   Скорость бегунка одинакова для всех. Размеры трёх зон задаются по архетипам в Tuning.
2. **Толпа мешает.** 3+ соседей-здоровых оттаскивают жертву (HELPER_SHOVE).
3. **Инкубация 30с.** Заражённый выглядит здоровым. Потом вскрывается.
4. **Скрытность.** Бежишь — подозрение растёт. Идёшь — незаметен.
5. **Обращение полицейского.** Полиция преследует и стреляет; механики ареста нет. Обращённый мент
   быстрее и заражает эффективнее. SWAT (с 40% заражения) в 5 раз крепче —
   но его обращение даёт мгновенную мутацию.
6. **Управление ордой.** ПКМ на агенте (здоровый/коп, радиус 3.5 ед.) — орда
   гонится за ним, отслеживая движение. ПКМ на пустом месте — позиционная цель.
   Работает на любом этаже. Когда цель заражена — метка снимается, орда держит
   последнюю позицию до истечения таймера (15 сек).
7. **План разработки.** Esc → «Переделки» / «Дорожная карта».
   Галочка означает принятую работу, а не просто написанный код.
   Список и статусы: `data/development_plan.json`; меню: `scripts/development_menu.gd`.
   После фактической приёмки поставить `accepted: true` в нужном пункте либо
   отметить его в меню и нажать «Сохранить отметки». Без приёмки не отмечать.
   В редакторской сборке отметки сохраняются в общем JSON; в экспортированной —
   локально в `user://development_acceptance.json`. Стабильные `id` не переименовывать.
   Будущие идеи не являются обязательствами на текущий проход.

## Архитектура — читать перед любой правкой

**Агенты живут в плоских массивах, НЕ в нодах.** 500 нод с `_process` уронят
FPS. Все данные — PackedArray в `sim.gd`, рисовка — девять `MultiMeshInstance3D`
по вариантам гражданских, полиции и SWAT. Анимации толпы запечены в текстуры
матриц костей; у агентов нет отдельных Skeleton3D или AnimationPlayer.
Игрок использует один отдельный скелет и AnimationPlayer из GLB.

Игрок и открыто заражённые используют `zombie_idle` / `zombie_walk` / `zombie_run`,
при захвате — `bite` с анимированной челюстью. Здоровые, LATENT и обычная полиция
сохраняют человеческую походку; жертва игрока/орды использует `resist`.

Никогда не создавай ноду на агента. Никогда не используй `get_node` в цикле.

### Пространственный хеш

Поиск соседей через `_rebuild_grid` / `_neighbors`, ключ `Vector3i(floor, cx, cy)`.
Ячейка `Tuning.GRID_CELL = 4.0`. Не заменяй на перебор.

### Система этажей

- `floor_idx[i] = 0` — улица
- `1..MALL_FLOORS` — этажи ТЦ
- `MALL_FLOORS+1+N` — внутри здания N
- `floor_y3d(floor_id)` → 3D высота для рендера

## Архетипы горожан

| Архетип | Доля | Скорость шкалы относительно базовой |
|---------|------|-------------------------------------|
| NORMAL | 60% | 1.0 |
| CHILD | 10% | 0.65 |
| ELDER | 15% | 0.80 |
| BRUTE | 10% | 1.85 |
| JOURNALIST | 5% | 1.05; фотографирует захват |

20% NORMAL/ELDER имеют телефон: видят панику → звонят за 4с → +2 копа, +22 подозрения.

## Мутации (каждые 25 заражённых)

Игра ставится на паузу, предлагает 3 из 7 мутаций на выбор:

| ID | Мутация | Эффект |
|----|---------|--------|
| 0 | Тихое вскрытие | вскрытие без паники/подозрения |
| 1 | Быстрая инкубация | 30с → 6с |
| 2 | Атака сзади | сужает опасные края шкалы, если жертва спиной |
| 3 | Широкий захват | радиус ×2 |
| 4 | Бесшумный бег | спринт не повышает подозрение |
| 5 | Автозахват | после заражения — хватаем ближайшего |
| 6 | Вирусная аура | заражённые медленно инфицируют рядом стоящих |

Обращение SWAT-агента → мгновенная мутация.

## Реплики горожан

`BarkSystem` в `scripts/barks.gd` — пул из 8 Label3D, макс. 3 пузыря на экране.
Приоритет вытесняет слабые реплики. Кулдаун на агента + кулдаун на категорию.

Подключение из `sim.gd`: `bark_event.emit(i, "категория", pos[i], floor_idx[i])`

Категории: `grabbed`, `broke_free`, `turning`, `spot_infected`, `spot_body`,
`flee_panic`, `cop_shoot`, `idle` (и ещё 11 в json).

## Что уже исправлено и не должно вернуться

- **Полиция не видит через всю карту.** Конус обзора + память 3с + рация.
- **Мент обращается в заражённого мента.** Флаг `was_cop` ставится ДО смены
  состояния в `_infect()`.
- **Импульс при срыве захвата ограничен** (`KNOCKBACK_SPEED`).
- **Захват использует шкалу и Space.** Скорость одинакова для всех целей;
  размеры зон зависят от архетипа. Убийство проще заражения, громила чаще вырывается.
- **LATENT входит в infected.** Не прибавлять latent повторно. Счётчики собираются
  после изменений состояний; HUD использует ту же численность населения.
- **Завершение только через `_finish_run`.** Исход фиксируется один раз.
  Смерть в тике останавливает обработку до проверки победы.
- **Рестарт сбрасывает окна и паузу.** Отложенная хроника старого забега не открывается.
- **Эвакуация удалена.** Не возвращать КПП, автобусы и роль организатора из старых копий.
- **Зависание после выбора мутации при полном дереве.** `_offer_mutations()`
  проверяет `available.is_empty()` и сбрасывает `_pending_mutation` без показа
  панели. Порог срабатывает каждые 25 заражённых — мутаций только 7,
  при ~240+ заражённых это неизбежно.
- **Приказы орде не работали в зданиях** — убрано условие `floor_idx[i] == 0`
  из блока движения орды. `MapGen.push_out` и `_clamp_world` корректно
  обрабатывают коллизии на любом этаже.
