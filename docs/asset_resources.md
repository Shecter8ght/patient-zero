## 2. texture.ninja — CC0-текстуры окружения

Ссылка: https://texture.ninja  
**5 101 текстура, все CC0/Public Domain**, без регистрации.

### Категории, релевантные для ТЦ и улиц «Пациент Ноль»

| Категория | Кол-во | Применение в игре |
|-----------|--------|-------------------|
| **Concrete** | 192 | Полы, стены, внешние фасады ТЦ, тротуары |
| **Plaster** | 192 | Внутренние стены магазинов, офисов |
| **Stone** | 334 | Мостовая, ступени, фундаменты зданий |
| **Wood** | 654 | Прилавки, двери, деревянные перекрытия |
| **Metal** | 120 | Перила, двери ТЦ, пожарные щиты |
| **Rust** | 294 | Ржавые трубы, металлические детали — атмосфера распада |
| **Paint** | 526 | Разметка на полу, стены с облупившейся краской |
| **Graffiti** | 30 | Уличные стены, туалеты, переходы |
| **Dirt** | 160 | Грязные углы, внешние тротуары |
| **Ground** | 75 | Асфальт, гравий для уличного слоя |
| **Cracks** | 248 | Decal-трещины поверх любых поверхностей |
| **Signs** | 241 | Таблички, вывески магазинов — для атмосферы ТЦ |
| **Blood** | 74 | Дополнительные пятна крови/decal-оверлеи (CC0!) |
| **Brick** | 136 | Внешние стены старых зданий на улице |

**Как использовать**: скачать PNG, импортировать как `StandardMaterial3D` с normal map.
Для decal-пятен крови — режим `Decal` + `CanvasTexture`, слой поверх пола.

## 3. store.godotengine.org — плагины и инструменты

Ссылка: https://store.godotengine.org  
Официальный магазин Godot, в основном бесплатное (MIT).

### Напрямую применимо

| Ресурс | Автор | Зачем |
|--------|-------|-------|
| **Phantom Camera** | Ramokz | Плавные переходы камеры, следование, зоны фокуса. Может заменить `camera_rig.gd` или дополнить изо-камеру плавным zoom-to-target при захвате. |
| **YA3 — Yet Another Animation Addon** | LiteralSoofa | Удобный слой поверх AnimationPlayer для 3D/2D — может помочь с переключением клипов игрока (zombie_idle↔bite↔walk). |
| **Color Grading** | Rytelier | Compositor-шейдеры для цветокоррекции. Полезно: красный/серый фильтр при высоком подозрении или при мутации-паузе. |
| **Footstepper** | Dragon1Freak | Автоматические звуки шагов по поверхности (CharacterBody3D). Если добавим звук — готовое решение. |
| **Health System** | John Söllner | Модульная система здоровья (2D/3D). Можно взять паттерн для будущих HP копов/SWAT вместо голых float-массивов. |

### Интересно на будущее

| Ресурс | Зачем |
|--------|-------|
| **Dialogue Manager** (Nathan Hoad) | Если добавим катсцены или брифинг-экран перед раундом — готовый branching-диалог. |
| **Terrain3D** (Tokisan Games) | Если карта выйдет за пределы плоского тайл-грида — высококачественный terrain с paint-слоями. |
| **GodotSteam GDExtension** | Steam-интеграция (ачивки, таблицы лидеров) — когда проект подойдёт к релизу. |

## Приоритеты внедрения

### Высокий (сейчас)
1. **texture.ninja → Blood (74 штуки)** — дополнительные decal-пятна крови поверх существующей системы `blood_pool.gdshader`.
2. **texture.ninja → Concrete/Plaster/Wood** — замена placeholder-материалов пола/стен в ТЦ.
3. **Quaternius Universal Animation Library** — если понадобятся новые анимации для архетипов (паника, смерть в падении).

### Средний (при доработке окружения)
4. **Color Grading** (Rytelier) — постпроцесс-подсказка игроку: красный виньетинг при высоком подозрении.
5. **texture.ninja → Signs/Graffiti** — вывески магазинов ТЦ, атмосфера.
6. **Phantom Camera** — плавный zoom при захвате / отдалении при панике.

### Низкий (будущие фичи)
7. **Footstepper** — звук шагов по разным поверхностям.
8. **GodotSteam** — Steam-ачивки при релизе.
