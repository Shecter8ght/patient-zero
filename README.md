# ПАЦИЕНТ НОЛЬ — стартовый проект

## Запуск
1. Godot 4.3+ → Import → выбрать `project.godot`
2. F5

## Управление
WASD — идти · Shift — бежать (палишься) · ЛКМ удерживать — захват · R — рестарт

## Работа с Claude Code
Открой папку и запусти `claude`. Файл `CLAUDE.md` уже описывает архитектуру
и запреты — не удаляй его, он экономит объяснения каждую сессию.

Проверка парсинга без окна: `godot --headless --quit`

## Где крутить баланс
Только `scripts/tuning.gd`. Все числа собраны там.
